# App policies

Public policies for SaurusLex applications. This repository contains policy documents and their static presentation only, not application source code.

## Published policy

- [Abatab privacy policy](https://sauruslex.github.io/app-policies/abatab/privacy/)
- Editable canonical text: `abatab/privacy/PRIVACY.md`.
- HTML presentation: `abatab/privacy/index.html`.

The HTML text must match the Markdown policy when edited. Styling is shared in `styles.css`; there are no external scripts, fonts or analytics.

## Hosting

GitHub Pages publishes the repository root from `main`. The `.nojekyll` file keeps the site static.

DejaView's existing policy and repository remain unchanged and are not included here.
